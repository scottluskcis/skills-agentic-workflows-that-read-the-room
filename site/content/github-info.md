## Recent GitHub updates worth learning

Quick, practical picks from the last couple of weeks (October 2026).

### Collaboration

- **Stacked pull requests are generally available.** Break big changes into a chain of small, reviewable PRs. Source: [GitHub Changelog, Oct 6](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available)
- **Triage role users or higher can archive pull requests**, helping keep PR lists tidy. Source: [GitHub Changelog, Oct 8](https://github.blog/changelog/2026-10-08-triage-role-users-or-higher-can-now-archive-pull-requests)
- **Draft pull requests now count toward PR limits.** Source: [GitHub Changelog, Oct 8](https://github.blog/changelog/2026-10-08-draft-pull-requests-count-toward-pull-request-limits)

### GitHub Copilot

- **Local sandboxing for GitHub Copilot is generally available**, a safer way to let Copilot run commands. Source: [GitHub Changelog, Oct 7](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available)
- **Discover local models in Copilot CLI.** Source: [GitHub Changelog, Oct 7](https://github.blog/changelog/2026-10-07-discover-local-models-in-github-copilot-cli)
- **New models:** Gemini 4 Argon ([Oct 13](https://github.blog/changelog/2026-10-13-gemini-4-argon-in-github-copilot)) and Claude Haiku 5.5 ([Oct 7](https://github.blog/changelog/2026-10-07-claude-haiku-5-5-in-github-copilot)). Source: GitHub Changelog
- **New to Copilot?** Read how to teach Copilot about your codebase. Source: [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-teach-copilot-about-your-codebase/)

### Security

- **Secret scanning blocks Anthropic keys by default** via push protection. Source: [GitHub Changelog, Oct 13](https://github.blog/changelog/2026-10-13-secret-scanning-blocks-anthropic-keys-by-default-adds-salesforce)
- **A purpose-built model for leaked secret detection** finds more secrets with less noise. Sources: [GitHub Changelog, Oct 7](https://github.blog/changelog/2026-10-07-purpose-built-model-for-leaked-secret-detection) and [GitHub Blog](https://github.blog/ai-and-ml/githubs-model-for-secret-detection-finding-more-secrets-with-less-noise/)
